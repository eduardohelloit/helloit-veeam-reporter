Como gerar o arquivo NDJSON
  1. No servidor VBR, abra o PowerShell com permissões de administrador.
  2. Execute scripts/collectors/collect_backups.ps1 (ajuste $Hours).
  3. O script coleta Get-VBRSession -Type Backup e enriquece por VM (task session).
  4. Gera backups_YYYYMMDD_HHMMSS.ndjson com uma execução de VM por linha.
  5. Faça o upload nesta tela. O período é detectado automaticamente.
