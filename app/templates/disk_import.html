Importar Backups em Disco

Faça o upload dos arquivos .ndjson exportados pelos coletores PowerShell collect_disk_backups.ps1 (pontos de restauração físicos) e, opcionalmente, collect_repo_capacity.ps1 (capacidade dos repositórios, usada para calcular o fator de calibração lógico → real). Como gerar os arquivos NDJSON
  1. No servidor VBR, abra o PowerShell com permissões de administrador.
  2. Execute scripts/collectors/collect_disk_backups.ps1 para gerar o arquivo de pontos de restauração físicos (disk_backups_YYYYMMDD_HHMMSS.ndjson).
  3. Execute também scripts/collectors/collect_repo_capacity.ps1 (opcional, mas recomendado) para gerar o arquivo de capacidade dos repositórios (repo_capacity_YYYYMMDD_HHMMSS.ndjson).
  4. Faça o upload dos dois arquivos nesta tela — o período coletado é detectado automaticamente.
