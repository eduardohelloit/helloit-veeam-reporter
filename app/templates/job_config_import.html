Como gerar o arquivo NDJSON
  1. No servidor VBR, abra o PowerShell como administrador Veeam.
  2. Execute scripts/collectors/collect_job_config.ps1 (padrão: coleta todas as rotinas).
  3. O script coleta configuração de cada rotina: schedule, repo, proxy, VSS, SQL tx log, retenção e objetos.
  4. Gera job_config_audit_ALL_YYYYMMDD_HHMMSS.ndjson — uma rotina por linha.
  5. Faça o upload nesta tela. O cliente deve corresponder ao ambiente VBR.
