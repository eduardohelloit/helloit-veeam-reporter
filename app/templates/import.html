Como exportar do Event Viewer
  1. Acesse o servidor VBR via RDP.
  2. Abra Event Viewer → Applications and Services Logs → Veeam Backup.
  3. Clique em Filter Current Log... e filtre os últimos 14 dias ou mais.
  4. Clique em Save Filtered Log File As... e salve como .evtx.
  5. Faça o upload do arquivo gerado nesta tela.
  6. O período será detectado automaticamente. Para gerar o relatório, acesse Relatórios → Novo Relatório.
