Como gerar o arquivo NDJSON
  1. No servidor VBR, abra o PowerShell com permissões de administrador.
  2. Adicione o snap-in do Veeam: Add-PSSnapin -Name VeeamPSSnapIn -ErrorAction SilentlyContinue
  3. Execute o script coletor (collect_offload.ps1) que exporta sessões do tipo ArchiveBackup.
  4. O script gera um arquivo offload_YYYYMMDD_HHMMSS.ndjson com uma execução por linha.
  5. Faça o upload do arquivo nesta tela. O período é detectado automaticamente.
